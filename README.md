# TinyTorque REAL

**Édition indépendante du jeu [TinyTorque](https://github.com/titomus/tiny-torque)**. Objectif : retrouver les quatre pilotes IA, les réglages mécaniques, la télémétrie et les défis de chrono dans un circuit RC à rendu plus immersif.

## Démarrage

Le jeu est statique et fonctionne dans un navigateur moderne. Pour jouer en local, lancer `python -m http.server 8000` à la racine et ouvrir http://localhost:8000. Three.js est téléchargé depuis un CDN, donc une connexion Internet est nécessaire.

## Fonctionnalités

- 4 voitures IA et 3 tours, physique de traction / propulsion / 4×4 et collisions
- 13 réglages et transmission modifiable, circuit avec barrières
- Chronos, records locaux, challenges partageables sur X
- Sauvegardes distinctes du TinyTorque classique
